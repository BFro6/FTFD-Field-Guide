FTFD SWONKY FIELD GUIDE v0.1 — TRAINING PROTOTYPE

Contains: index.html, app.js, sw.js, manifest.webmanifest, protocols.json, swonky-2026.pdf, icons.

DEPLOY
1. Extract ZIP, preserving all files in the same folder.
2. Upload all files to the root of a GitHub Pages repository (or another HTTPS static web host).
3. Enable GitHub Pages: Settings > Pages > Deploy from branch > main > / (root).
4. Open the published HTTPS URL in Safari on iPhone.
5. Share > Add to Home Screen. Launch once with internet access and wait for offline cache installation. Test in airplane mode.

IMPORTANT
- Do NOT open index.html using file://; service workers require HTTPS or localhost.
- This is not approved for patient care. Extracted text and categorization have not been clinically validated.
- Use original PDF for figures, tables, and authoritative protocol wording.
- Offline PDF availability depends on available browser storage and successful initial caching.
- No dose calculator or automated clinical recommendations in v0.1.
- A production release requires medical director signoff, content audit, accessibility review, security review, and version/update controls.
